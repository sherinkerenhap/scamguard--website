How ScamGuard Works

The platform follows a simple analysis workflow to provide understandable scam-risk information.

01

User Input

The user enters a suspicious message, email, SMS, WhatsApp text or URL.

↓
02

Preprocessing

The input is cleaned and prepared for analysis.

↓
03

Scam Indicator Analysis

The system checks suspicious words, URLs, urgent requests and sensitive-data requests.

↓
04

Risk Assessment

Detected indicators are converted into a transparent risk score and risk level.

↓
05

User Recommendation

The system explains the indicators and provides a safety recommendation.
